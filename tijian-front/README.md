# 用户端前端

使用 Vue 3、Vue Router、Axios、Font Awesome 与 Vue CLI Service 5.0.9。参考实践手册用户端流程，现有注册登录、首页、机构和套餐选择、预约日历、确认与提交预约、预约列表及取消、报告列表和详情、个人中心。

## 本机访问

用户端：http://127.0.0.1:8081/ ；医生端：http://127.0.0.1:8089/ 。前端使用开发代理连接用户端后端 `127.0.0.1:8080`。需启动 MySQL 和对应后端后使用。

在 `tijian` 目录分别打开两个 PowerShell 窗口：

```powershell
# 用户端后端
. .\启用项目环境.ps1
$env:TIJIAN_DB_PASSWORD = '你的数据库密码'
mvn.cmd -f .\tijian-server\pom.xml spring-boot:run
```

```powershell
# 用户端前端
cd .\tijian-front
npm.cmd install
npm.cmd run serve
```

可以注册虚构测试账号；也可用演示账号 `19900000001`、密码 `Demo123456` 登录，查看已归档报告。医生端示例账号与启动步骤见 `../tijian-cms-front/README.md`。

## 文件

- `package.json`、`package-lock.json`：依赖清单和锁定版本。
- `vue.config.js`：前端端口及 `/tijian` 后端代理。
- `public/index.html`：HTML 入口。
- `public/img/`：从原始 `img(1).rar` 提取的手册配套图片。
- `src/main.js`：挂载 Vue、路由和图标样式。
- `src/router/index.js`：hash 路由及前端登录跳转。
- `src/App.vue`：用户端各页面、交互和样式。

## 当前范围

支持本人和家属预约；套餐卡片可展开检查项目与明细。示例医院配置为周一至周五每天 20 个名额，日历展示剩余名额，预约提交时重新检查。当前尚无支付、医院排班管理页面或节假日例外规则。医生端需保存全部检查结果并添加总检结论后才能归档，用户可查看已归档报告及异常项汇总。

用户端使用服务端会话和 BCrypt 密码存储，预约和报告由服务器检查归属；前端 sessionStorage 仅保存显示信息。当前仍为本地开发环境，正式使用前需配置 HTTPS、CSRF 防护、登录限速并完成安全审查。

## 手册图片素材

首页使用原始横幅、服务图标、健康影像与资讯图片；本人/家属选择使用原预约图片，成功页使用温馨提示图片，个人中心使用原头像。未实现的在线咨询与健康评估入口没有展示。

## 医生介绍

首页的“医生介绍”可进入医生列表及详情；资料定义在 `src/data/doctors.js`，可在该文件维护姓名、科室、简介和服务方向。页面将 8 张原始照片与 8 条编号介绍一一对应。原始资料未提供可核实的姓名和履历，当前编号及通用说明由项目编写，不应作为照片中人物的真实身份或专业资质。
